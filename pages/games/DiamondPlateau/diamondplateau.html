Diamond Plateau

A 2D rage platformer built in Unreal Engine 5 using Blueprints. Survive six progressively difficult levels and reach the diamond at the end.

RELEASE / MAY 2, 2025GENRE / 2D PLATFORMER / RAGE GAMEENGINE / UNREAL ENGINE 5 · BLUEPRINTS
Play / Download ↗Source on GitHub ↗

About the game

The objective is to reach the final diamond. The challenge is fast reflexes, pixel-perfect jumps, and patience. The game is built entirely with visual scripting, without C++.

Features

Gameplay

  • Six progressively difficult stages.
  • Responsive movement and precision jumps.
  • Custom traps, obstacles, and level design.
  • Timer, checkpoints, and clean minimal UI.
