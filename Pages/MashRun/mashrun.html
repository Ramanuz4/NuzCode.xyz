Description :

Rage Platformer is a 2D platformer game developed in Unreal Engine 5 using its Blueprint system. The game features 6 carefully designed levels with increasing difficulty, challenging players precision, timing, and resilience. The ultimate goal? Reach the diamond at the end — if you can.
